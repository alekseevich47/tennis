# 🎾 Настольный Теннис — Мобильное Mini App под платформу MAX

Высокотехнологичное SPA-приложение (Single Page Application) для участников теннисной секции «Секция Миленьких». Проект разработан с учетом строгих требований к производительности мобильного Webview мессенджера MAX, поддерживает нативные жесты со скоростью 60 FPS, реактивное обновление данных в реальном времени и защищенную сквозную авторизацию.

---

## 🛠 Технологический стек (Architecture & Stack)

-   **Frontend:** React 18, Vite 5 (сборка бандла под стандарт ESM/MJS), Чистый JavaScript (вместо тяжелых внешних библиотек для жестов).
-   **Backend & СУБД:** PocketBase v0.23+ (высокопроизводительный сервер на Go с embedded SQLite).
-   **Web Server & Network:** Nginx (Reverse Proxy) с поддержкой HTTP/2, Certbot SSL (Fullchain), кэшированием статики и рейт-лимитами (`limit_req_patches`).

## 🚀 Реализованный функционал (Core Features)

### 1. Авторизация и профиль игрока (MAX Bridge UI)
-   Сквозная бесшовная инициализация сессии на основе валидации строки `window.WebApp.initData`.
-   Защита от подмены ID пользователей на стороне бэкенда.
-   Динамический профиль спортсмена: автоматический рендеринг имени, возраста, игровой руки, игровой статистики побед/поражений.

### 2. Интерактивная лента новостей (Advanced News Feed)
-   **Публикация медиа:** Оптимизированная упаковка бинарных потоков в `FormData` с обходом лимитов Nginx (`client_max_body_size 50M`) для загрузки тяжелых фото.
-   **Плавающая кнопка модератора:** Анимированный триггер создания постов с автоматическим скрытием (Debounce) при скроллинге ленты для разгрузки экрана.
-   **Нативный Pinch-to-Zoom:** Масштабирование картинок двумя пальцами с использованием матрицы трансформаций CSS и `window.requestAnimationFrame`.
-   **Кинематическое скольжение:** Реализация плавной инерции (коэффициент трения `friction = 0.94`) при перетаскивании увеличенного изображения.
-   **Жест Swipe-to-Close:** Закрытие полноэкранного просмотра плавным смахиванием картинки вверх или вниз с динамическим изменением прозрачности фона.

### 3. Реактивная система комментариев (Realtime Comments)
-   **Прямая выборка:** Высокоскоростной рендеринг обсуждений напрямую из коллекции `comments` по индексированному фильтру `post = ID`, исключающий кэш-задержки связей PocketBase.
-   **Превью в ленте:** Мгновенный вывод блоков с 2 последними комментариями под каждым постом без перезагрузки страниц.
-   **Инлайн-модификация:** Возможность добавления, удаления и редактирования текста по точным ячейкам схемы бэкенда (`text`).
-   **Таймстампы:** Форматирование времени написания комментариев по регламенту: `HH:MM DD.MM.YYYY`.

### 4. Паттерн мягкого удаления (Soft Delete Mechanics)
-   Двухуровневая изоляция удаленных данных для постов и комментариев.
-   При клике на `✕` запись скрывается от обычных пользователей мгновенно, а модератор или автор видят лаконичную текстовую ссылку «Восстановить».
-   Синхронизированные сессионные перехватчики в корневом файле `App.jsx`, которые безвозвратно вычищают (вызывают физический метод `delete()`) скрытые записи при переключении табов меню или жестком закрытии сессии приложения.

### 5. Интерактивный календарь тренировок (Trainings Scheduler)
-   **14-дневный топ-бар:** Горизонтальная скролл-лента дней недели, автоматически рассчитываемая от текущей даты смартфона (строго 7 элементов в ряд на ширину экрана).
-   **Умная мульти-маркировка:** Автоматическое сканирование СУБД и подсветка дней цветными точками (серая — пусто, синяя — групповая, красная — турнир). При наличии двух событий в один день маркеры выстраиваются в горизонтальный ряд.
-   **Неоновый таймлайн:** Пульсирующее градиентное свечение нижней кромки карточек занятий (синее свечение для тренировок, красное — для турниров).
-   **Контроль слотов:** Круглая смарт-кнопка (`+` / `✕`), блокирующая запись со статусом «Мест нет» при достижении лимита `max_slots`.
-   **Custom Alert UI:** Полный отказ от системных браузерных окон в пользу кастомного анимированного компонента `CustomAlert.jsx` с эффектом `backdrop-filter: blur`.

## 🗺 Схема сетевой маршрутизации Nginx (Reverse Proxy Config)

```nginx
### Статика клиентского Mini App
    location /tt-api/ {
        alias /home/sa/tt_bot/client/dist/;
        index index.html;
        # Важно: добавляем префикс пути к index.html для корректной работы alias
        try_files $uri $uri/ /tt-api/index.html;

        # Добавляем кэширование статики (картинки, скрипты)
        location ~* \.(?:js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2)$ {
            expires 1y;
            add_header Cache-Control "public, no-transform";
        }
    }

### === 4. PocketBase TT Bot API ===
    location /tt/api/ {
        proxy_pass http://pocketbase_tt/api/; # /api/ Слэш в конце важен
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
   }
```
